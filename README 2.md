# Personal Projects

This repository contains two portfolio-ready analytics projects built in Python.

## Projects

### 1. Employee Attrition Analysis Using Machine Learning
End-to-end HR analytics project using logistic regression, preprocessing pipelines, ROC-AUC evaluation, and driver analysis.

Folder: `attrition-analysis-ml`

### 2. Screen Time and Emotional Well-Being Analysis
Statistical modelling project using logistic and linear regression to study how platform usage and engagement relate to emotional well-being.

Folder: `screen-time-wellbeing-analysis`

## Tools Used
Python, Pandas, NumPy, Matplotlib, scikit-learn, statsmodels, openpyxl

## How to Use
Open each project folder and follow its README for setup and execution.
